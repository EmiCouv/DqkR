# DqkR 2027 — boutique fictive

Mini-site statique parodique pour la campagne fictive DqkR 2027.

- Ouvrir `index.html` localement ou le déployer comme site statique.
- Les images des fiches produit sont dans `assets/`.
- Le panier et les prix sont simulés : aucun achat ni paiement réel, aucune collecte de données.
